# ARANKUB — เดโม

หน้าจอจริงของระบบ ARANKUB ที่รันได้บนเครื่องของท่านภายในไม่กี่นาที
**ข้อมูลทั้งหมดเป็นข้อมูลจำลอง ไม่มีข้อมูลผู้ป่วยจริงแม้แต่รายการเดียว**

← กลับไปที่ [เอกสารระบบฉบับเต็ม](../README.md)

---

## รันเดโม

ต้องมี **Node.js 20 ขึ้นไป** อย่างเดียว ไม่ต้องมีฐานข้อมูล ไม่ต้องมี HosXP ไม่ต้องตั้งค่าอะไรเพิ่ม

```bash
git clone https://github.com/payang24-DRCOMP/ARANKUB
cd ARANKUB/demo
npm install
npm run dev
```

เปิด http://localhost:3000

## มีหน้าอะไรให้ดูบ้าง

| หน้า | ดูอะไรได้ |
|---|---|
| **หน้าแรก** `/` | รวมลิงก์เข้าแต่ละหน้าจอ |
| **ARANKUB AI** `/ai` | ภาพรวมโรงพยาบาล — ผู้ป่วยนอก/ผู้ป่วยใน การครองเตียงรายวอร์ด ความหนาแน่นแต่ละจุดบริการ รายงาน การเงิน และผู้ช่วย AI |
| **DRG Analyzer** `/drg-analyzer` | รายการเคสผู้ป่วยใน ตัวกรอง และหน้าตรวจความครบถ้วนของรหัส |
| **คลังความรู้** `/rag` | รายการคลังความรู้ที่ระบบใช้อ้างอิง และหน้าทดสอบการค้นหา |

### ลองเล่นตรงนี้

- ในหน้า **ARANKUB AI** เลือกแท็บ **ผู้ช่วย AI** แล้วลองถาม
  - `สรุปยอดผู้ป่วยนอกวันนี้` → ตอบเป็นตาราง
  - `ทำตารางเปรียบเทียบครองเตียงแต่ละวอร์ด` → ตอบเป็นตาราง
  - `วาดกราฟโรคที่พบมากที่สุดเดือนนี้` → ตอบเป็นกราฟจริง
  - `แนวโน้มรายรับเทียบปีก่อน` → ตอบเป็นกราฟเส้น
- สลับมุมมอง **เว็บ / มือถือ** ที่มุมบนขวา
- ตัวเลขผู้ป่วยนอกจะเดินตามเวลาจริงของวัน (มากขึ้นเรื่อย ๆ ระหว่าง 07:00–16:00)

## เดโมนี้ต่างจากระบบจริงอย่างไร

### สิ่งที่เหมือนของจริงทุกอย่าง

หน้าจอ การจัดวาง กราฟ ตาราง และการโต้ตอบ — เป็นโค้ดชุดเดียวกับที่ใช้งานจริงที่โรงพยาบาลอรัญประเทศ

### สิ่งที่ต่าง

| | เดโม | ระบบจริง |
|---|---|---|
| ข้อมูล | สร้างขึ้นในโค้ด | อ่านจาก HosXP ผ่านฐานข้อมูลที่ sync ไว้ |
| ผู้ช่วย AI | ตอบข้อความสำเร็จรูปตามคำที่พบในคำถาม | โมเดลภาษาที่รันบนเครื่องของโรงพยาบาล ตอบจากข้อมูลจริง |
| วิเคราะห์รหัส | ผลตัวอย่างคงที่ | ค้นเกณฑ์จากคลังความรู้ + โมเดลภาษา + กฎการลงรหัส |
| คำนวณ DRG | ใช้ไม่ได้ | ThaiDRG Grouper |
| ตรวจชาร์จจากภาพ | ใช้ไม่ได้ | OCR อ่านเอกสารภาษาไทย |
| คลังความรู้ | รายการตัวอย่าง | Qdrant ที่มีเอกสารจริงนำเข้าไว้ |
| ล็อกอิน / สิทธิ์ | ไม่มี | รหัสผ่านหรือ Provider ID สธ. + 2FA + สิทธิ์ราย 18 โมดูล |

ปุ่มที่ต้องใช้ Grouper, OCR หรือโมเดลภาษาจริง จะขึ้นข้อความบอกว่าใช้ได้เฉพาะระบบที่ติดตั้งจริง
ไม่ได้ค้างหรือพังเงียบ ๆ

## สิ่งที่ไม่ได้อยู่ในเดโมนี้

เดโมมี 3 หน้าจอจาก **18 โมดูล** ของระบบเต็ม ส่วนที่ไม่ได้รวมมา

OPD Analyzer · ODS ผ่าตัดวันเดียว · REP ผลตรวจสอบ สปสช. · กองทุนและการเบิกจ่าย ·
ส่งยาที่บ้าน · ลูกหนี้/การเงิน · ประกันสังคม · ตรวจคุณภาพ 43 แฟ้ม · HDC ·
รายงานตรวจสุขภาพ · เครื่องมือเขียน SQL · ระบบผู้ใช้และสิทธิ์ · ตั้งค่าระบบ

และตรรกะเชิงเนื้อหาที่เป็นหัวใจของระบบ — กฎการลงรหัส เกณฑ์คัดกรอง ODS
ตัวอ่านไฟล์ของ สปสช. และชั้นเชื่อมต่อ HosXP — ไม่ได้อยู่ในเดโม
เพราะส่วนเหล่านี้ต้องปรับตามเกณฑ์ที่เปลี่ยนทุกปีและตามโครงสร้างข้อมูลของแต่ละหน่วยบริการ

## โครงสร้างโค้ด

```
demo/
├── src/app/
│   ├── page.tsx              หน้าแรกรวมลิงก์ (มีเฉพาะในเดโม)
│   ├── ai/                   ARANKUB AI
│   ├── drg-analyzer/         DRG Analyzer
│   ├── rag/                  คลังความรู้
│   └── api/                  API จำลอง — ระบบจริงต่อ HosXP / Qdrant / Ollama
├── src/components/
│   ├── arankub/              หน้าจอ ARANKUB AI (โค้ดเดียวกับระบบจริง)
│   ├── rag/                  หน้าจอคลังความรู้
│   └── ui/                   คอมโพเนนต์พื้นฐาน
└── src/lib/demo-data.ts      ตัวสร้างข้อมูลจำลองทั้งหมด
```

อยากเปลี่ยนตัวเลขที่เห็นบนหน้าจอ แก้ที่ `src/lib/demo-data.ts` ที่เดียว
